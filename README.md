# 🚀 QuickHire – A Full Stack Job Portal built using MERN stack

QuickHire is a production-ready full-stack Job Portal built using the MERN stack.
It enables recruiters to post jobs and manage applicants while allowing job seekers to explore, filter, and apply for opportunities — all within a secure, responsive SaaS-style platform.

---

## 🌟 Core Highlights:-

- 🔐 Secure authentication with Clerk

- 🏢 Recruiter dashboard with job management

- 👨‍💼 Job seeker application tracking

- 💰 Smart currency formatting (₹ / $ based on location)

- 🎨 Stripe-style modern UI with TailwindCSS

- ⚡ Fully responsive & animated interface

- 🌍 Role-based access control

---

## 🌟 Features:-

### 👨‍💼 For Job Seekers

- Secure authentication (Clerk)

- Browse and search jobs

- Filter by location, salary, category

- Apply for jobs

- Track application status

- Responsive UI

### 🏢 For Recruiters

- Company registration

- Post new jobs

- Manage job listings

- View applicants

- Accept / Reject applications

- Dashboard analytics

---

## 🛠 Tech Stack:-

### Frontend

- React (Vite)

- TailwindCSS

- Framer Motion

### Backend

- Node.js

- Express.js

- MongoDB + Mongoose

## ⚙️ Installation Guide:-

### 1️⃣ Clone the Repository

- git clone https://github.com/VigneshRav/Job_Portal.git

- cd quickhire

### 2️⃣ Install Dependencies

**Install Server**

- cd server

- npm install

**Install Client**

- cd client

- npm install

---

## 🔑 Environment Variables:-

**Create .env files in both client and server.**

See:

- /server/.env

- /client/.env

---

## ▶️ Running the Project:-

**Start Backend**

- cd server

- npm run dev

**Start Frontend**

- cd client

- npm run dev

---

## 🌍 Deployment:-

**You can deploy using:**

- Frontend → Netlify / Vercel

- Backend → Render / Railway
