# 💻 QuickHire - A Full Stack MERN Job Portal (Frontend)

This is the frontend of QuickHire Job Portal built using React, Vite, and TailwindCSS.

---

## ⚙️ Tech Stack:

- React (Vite)

- TailwindCSS

- React Router DOM

- Context API

- Clerk Authentication

- Axios

- Framer Motion

- React Toastify

- Cloudinary image rendering

---

## 🎨 UI Features:

- Modern Stripe-style SaaS UI

- Fully responsive

- Animated components using Framer Motion

- Dynamic salary currency formatting

- Conditional rendering based on user role

---

## 🧩 Main Pages:

- Home Page

- Job Listings

- Job Details

- Apply Job

- Recruiter Dashboard

- Post Job

---

## 🔐 Authentication:

- Authentication is handled using **Clerk**.

---

### Required Environment Variables:

- Create a `.env` file inside `/client`:

VITE_CLERK_PUBLISHABLE_KEY=your_clerk_key
VITE_BACKEND_URL=http://localhost:5000

---

## 🚀 Running the Client:

- cd client
- npm install
- npm run dev
- App runs on: http://localhost:5173

---

## 📦 Build for Production:

- npm run build

---

## 🌍 Deployment:

Recommended:

- Netlify

- Vercel

---

## 🛠 Common Issues:

**1. API URL showing undefined**

- Make sure:

VITE_BACKEND_URL

is correctly defined.

**2. Clerk not loading**

- Ensure publishable key is correct.
